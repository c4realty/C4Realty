# C4 Realty · Página web

Casas, terrenos, fincas y alquileres en Chiriquí. Instagram: [@c4realty1](https://www.instagram.com/c4realty1/) · WhatsApp 6253-1751 · c4realty1@gmail.com

## Estructura
- `index.html` — la página completa (catálogo, cotizar, Bono Pa' Ti, videos, contacto).
- `img/` — fotos de las publicaciones de Instagram y el logo.
- `videos/` — videos de los proyectos (MP4) y sus portadas.

## Cómo actualizar una propiedad
Las propiedades están en `index.html`, en la lista `const P=[ ... ]`. Cada una tiene nombre, zona, precio, características y los códigos de sus publicaciones de Instagram.

## Publicación
Se publica con Cloudflare Pages conectado a este repositorio: cada cambio que se sube a `main` se publica solo.
